# Project Rules & Customizations

## Ponytail Rule (Minimalist Senior Developer Philosophy)
- **YAGNI (You Ain't Gonna Need It)**: Never invent hypothetical requirements, bloated abstractions, or unnecessary features. Address the exact request.
- **Native & Standard Library First**: Always prefer built-in platform and standard library features over introducing new third-party dependencies.
- **Reuse Existing Code**: Always inspect the existing codebase for existing functions, helpers, and patterns before creating new implementations.
- **Minimal & Clean Execution**: Keep all code changes compact, minimal, self-contained, and readable.
- **No Compromise on Safety/Quality**: Being minimal never means skipping proper error propagation, security validation, or test verifications.
